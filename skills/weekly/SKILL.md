# 周报技能

## 概述
此技能用于回顾本周的对话历史，生成工作总结，帮助用户了解一周内完成了哪些任务。

## 使用时机
- 用户说"这周做了什么"
- 用户说"生成周报"
- 用户说"本周回顾"
- 用户说"一周总结"

## 执行步骤

1. 读取会话历史记录（存储在 ~/.mini-openclaw/sessions/）
2. 筛选出最近一周（7天内）的用户对话
3. 整理对话内容，按主题分组
4. 用 LLM 总结主要工作内容
5. 输出简洁的周报

## 输出格式
```
📊 本周回顾

1. [工作内容1]
2. [工作内容2]
3. [工作内容3]
...

总计对话: X 次
```

## 注意事项
- 如果本周没有对话，回复"这周还没有聊过天呢~"
- 忽略以"【Summary】"开头的系统消息
- 优先关注用户发起的有意义的任务
- 保持总结简洁，3-5 条即可
