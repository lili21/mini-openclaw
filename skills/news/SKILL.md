# 每日新闻技能

## 概述
此技能用于获取当日的热点新闻和科技资讯，帮助用户快速了解正在发生的事情。

## 使用时机
- 用户说"今天的新闻"
- 用户说"有什么热点"
- 用户说"科技趋势"
- 用户说"今日要闻"

## 执行步骤

1. 使用 web_search 工具搜索 "今日热点新闻" 或 "top stories technology"
2. 整理搜索结果，用中文总结 3-5 条最重要的新闻
3. 每条用 1-2 句话说明，保持简洁

## 输出格式
```
📰 今日热点新闻

1. [新闻标题1]
   [简短描述]

2. [新闻标题2]
   [简短描述]

...
```

## 注意事项
- 如果搜索结果为空，回复"今天没有获取到新闻~"
- 优先选择科技相关新闻
- 保持内容简洁有价值
